# 使用 UniLab 资产库

把已有镜像或 OSS 发布目录接到同一套网页和 Blender 入口。随包包含网页、桥接服务、插件及本地代码依赖。新电脑只需配置 OSS 地址与读取凭据，先拉目录，再按需下载模型。

## 先确定入口

首次使用先运行 `python scripts/manage.py doctor`。检测到未配置 OSS、缺少凭据或读取权限被拒绝时，由使用本技能的助手明确提示用户：“请联系 chang 申请资产库只读权限和连接配置”，再按 [OSS 引导](references/oss.md) 完成本机配置。联系人提示维护在本技能中，网页和运行时报错只提供通用诊断及技能指引。凭据由用户在本机安全配置，不索取聊天中的明文密钥。配置存在不代表权限有效，用 `doctor --config-dir <目录> --check-oss` 检查两个目录入口；失败不删除现有镜像。

1. 确定目标机器的资产库根目录和 Python。已有镜像先检查服务；空目录按 [OSS 初始化与按需下载](references/oss.md) 执行 `configure → bootstrap → start`，无需手工复制模型。有效镜像有根 `library.json`、`统一目录/library.json` 及所需条目和字典。
2. 设备广场默认 `http://127.0.0.1:8766/`，固定版本桥接服务默认 `http://127.0.0.1:8765/`。检查两个 `/api/health` 的 `root` 是否指向同一镜像；服务在运行不等于它连接了正确的库。
3. 根据请求读取对应指南：
   - 初装、换电脑、启动或连接错误：[部署与诊断](references/deployment.md)。
   - 网页分类、场景、模型和 OS module 检索：[设备广场](references/web.md)。
   - Blender 安装、插入、摆放、编辑副本和清单导出：[Blender 插件](references/blender.md)。
   - 本机已知路径只是定位线索：[本机配置案例](references/local-example.md)。

## 消费约定

- 公共条目 UUID、工程 `catalog_id`、模型 `asset_id` 和 `package_digest` 分别保留。通过服务返回的映射和固定引用消费，不能只按中文名或颜色选模型。
- 统一广场显式提供设备、零部件、模组、耗材、工站、工具及专题入口。只有设备使用场景／阶段全景图；其他类型与全部资产使用多层分类目录、面包屑和资产卡片。切换非设备类型时清除学科／场景／阶段条件。
- 分类切换选项忽略本分类轴的已有选择，保留厂家等其他轴条件；结果卡片仍使用全部条件。大类与具体分类视为同一分类轴；场景、阶段、学科按同一条场景绑定匹配。分类目录分别显示全部、已分类和待补分类计数，不能把已分类数当总数。专题是当前资产的项目归属／场景索引，不是历史资产包，不复制模型。
- 产品登记、有 3D 模型、可插入、OS module 已登记、行为已验证是不同状态。模型预览和模块入口存在不代表运动、接触或真机驱动已通过验收。
- 网页负责浏览和取得引用；Blender 通过桥接服务准备固定包，再创建实例。保留安装位姿和实例身份；编辑从“转为可编辑副本”开始。
- 当前索引中的版本是默认选择；固定旧版本缺失时报告缺口。保留 `retired_package_digests`，避免远端旧目录把已清理版本带回。用户请求历史重现时另行确认可获得的固定版本。
- 来源资料、当前标准包、工作缓存各有用途。日常浏览不执行清库或重新发布；用户明确要求这些动作时切到资产管线工作流。

## 随包工具

在技能目录运行 `python scripts/manage.py --help`。`configure` 生成目标机器配置，`bootstrap` 从 OSS 拉取同一发布快照的工程和公共目录及预览，`prepare` 下载并校验所选模型，`start` 启动两项服务，`check` 核对入口与库根，`verify-bundle` 校验随包代码摘要。全部路径以技能位置或用户传入参数解析。

`assets/unilab_asset_browser.zip` 是可安装的 Blender 插件；`assets/runtime/tools/` 是网页与桥接服务源码。`scripts/bundle_runtime.py` 从指定源码仓更新分发文件，并生成来源摘要清单。它不复制运行配置、凭据、资产模型或缓存。

## 完成判据

按本次任务报告实际验证范围：云端初始化应从空目录实际下载，并证明目录阶段没有下载模型主体；网页检索检查结果和非空分类；部署核对两端库根；Blender 插入检查根实例、固定引用、单位和摆放。仅 HTTP 200 或插件导入不代表模型插入、动画或物理验证通过。交接提供技能包、插件 ZIP、无密钥 OSS 配置及命令。云端发布快照可能落后于源机器，报告实际计数和摘要，不把本机未发布条目说成已可下载。
