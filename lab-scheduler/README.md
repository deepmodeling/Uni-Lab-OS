# Lab Scheduler

## Compiler Service

`POST /api/v1/compile` 将用户编写的物料/容器级步骤编译成真实执行 DAG。编译后的每个 `Step` 都对应一次设备下发，可直接作为 `ScheduleRequest` 提交给 `/api/v1/schedule`。

适用场景：用户只描述每步使用的仪器和处理的物料，通量由容器隐含，例如 `plate96 -> plate24` 自动物化为 4 个 24 孔板处理节点。

Python 直调:

```python
from scheduler import CompilerRequest, CompilerService

compiled = CompilerService().compile(CompilerRequest(**payload))
schedule_request = compiled.schedule_request
```

HTTP:

```bash
curl -X POST http://localhost:8090/api/v1/compile \
  -H 'Content-Type: application/json' \
  -d @compiler_request.json
```

Compiler 只负责物化固定 DAG, 不做资源调度。调度仍由 `/api/v1/schedule` 完成。

算法对比与选择建议
算法类型	                        优点        	                缺点                        	            适用场景
