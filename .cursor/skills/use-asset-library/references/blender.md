# Blender 插件

随包 `assets/unilab_asset_browser.zip` 版本 0.3.0，声明 Blender 5.1+；验收环境是 Blender 5.1。Blender、资产模型和云凭据不在 ZIP 中。

## 安装及连接

新电脑没有资产镜像时，先按 [OSS 初始化流程](oss.md) 拉取目录并启动服务；插件会在插入所选资产时下载其模型包。

1. Blender 偏好设置 → 插件 → 从磁盘安装，选择 ZIP，启用 **UniLab 设备广场**。已有插件时先检查版本和路径；更新代码需保留用户偏好、本机 `runtime.json` 和场景，重新载入插件后生效。
2. 插件偏好设置中“设备广场服务”指向 `http://127.0.0.1:8766`，“目录服务”指向 `http://127.0.0.1:8765`。改端口时两项都按配置更新。
3. 3D 视图按 `N`，打开 **UniLab**，点击“刷新目录”；“打开宽幅设备广场”提供较宽的选择窗口。“打开网页目录”进入 8766。
4. 如需插件自动启动服务，把 `manage.py configure` 生成的 `runtime.json` 复制到已安装的 `unilab_asset_browser` 目录。文件包含目标机器的绝对路径，仅在本机生成；迁移电脑后重新生成，不写进分发 ZIP。

## 插入与编辑

按分类、场景、型号选条目，核对来源与可插入状态。默认“点击资产名称即插入”开启；只想检查详情时关闭此项。插入前放好 3D 光标，点击“插入到 3D 光标”。重复插入同一资产用该按钮。

桥接服务先按固定摘要准备完整包：本地有效包直接校验，缺失包才从已配置 OSS 下载。损坏包会报错，不应通过取消校验来继续。仅产品登记、未转换或缺模型的条目不可插入。

移动、旋转实例根对象完成摆放。同源实例共享来源几何，实例 ID 各不相同。通过“转为可编辑副本”修改网格，保存为项目草稿；这不构成资产库发布。普通 `Shift+D` 可能复制实例 ID，导出会拒绝重复 ID。

“导出实例清单”保存固定资产引用、实例身份、米制位姿与草稿状态。`.blend` 保存几何，插件不是 CAD 编辑器或 OS graph 自动发布工具。工站插入只表示布局预览；行为、关节驱动、OS 调度需在相应运行系统验收。

## 检查

确认有新的实例根对象、模型尺度与方向正确、位置对应 3D 光标；重复插入时 ID 不同。需要交接时保存并重开 `.blend`，再读回实例清单。透明度的实际显示依赖 Blender USD/材质支持和视图模式，不用“导入成功”替代外观检查。
