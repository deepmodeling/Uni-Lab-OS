## 设备

### 堆栈(S01, S02, S03, S10, S11)

### S04

- `run_stirring`: 执行 S04 磁搅加工

### S05

- `take_photo`: 执行烧杯姿势拍照检测

### S06

- `transfer_liquid`: 执行 S06 单步转液
- `run_solvent_addition`: 执行 S06 泵加液完整流程

### S07

- `scan_powder_cartridges`: S07 粉罐扫码盘点
- `rotate_powder_cartridge_to_feed`: S07 替换粉罐旋转到进料位
- `dose_powder`: S07 注粉

### S08

- `process_cap`: S08 开/关盖

### S09

- `check_home_position`: 读取 S09 指定安全位原点信号
- `read_home_positions`: 读取 S09 四个安全位原点信号
- `go_to_safe_position`: 执行 S09 去安全位工艺并确认原点信号
- `prepare_liquid_station`: 确认 S09 唯一加液工位空闲
- `read_allow_process`: 读取 S09 允许加工信号
- `bind_sample_to_station`: 绑定样品到 S09 加液工位
- `release_station`: 释放 S09 加液工位绑定
- `run_process`: 执行 S09 单个 PLC 工艺
- `add_liquid`: 执行 S09 单次业务加液流程
- `add_liquid_to_beaker`: 执行 S09 烧杯加液流程
- `run_liquid_workflow`: 执行 S09 多步加液工作流
- `set_liquid_bottle_remaining_volume`: 写入 S09 单个液体瓶剩余液量
- `initialize_liquid_bottle_remaining_volumes`: 初始化 S09 1-5 号液体瓶剩余液量
- `read_balance`: 读取 S09 天平读数
- `get_pipetting_status`: 读取 S09 移液站状态

## 位置信号

### 子设备 action 位置参数

- S04 磁搅：`position` 范围 1-4；写入/读取 `S04{position}磁搅工艺选择`、`S04{position}允许加工`、`S04{position}加工完成` 等变量；机械臂取放料使用 `S04取放料编号`
- S05 拍照：固定单工位，无位置入参；拍照结果读取 `S05加工完成`、`S05拍照结果`；机械臂占位传感器为 `传感器状态_上位机[3].NO[0]`
- S06 泵：固定单工位，工艺位置由 `process` 区分 1/2/3；写入 `S06工艺选择`、`S06参数写入完成`；烧杯在位传感器为 `传感器状态_上位机[3].NO[1]`
- S06 储液瓶：`process=1/2/3` 对应 1 号、2 号或双泵；储液瓶在位检测为 1 号 `传感器状态_上位机[4].NO[12]`、2 号 `传感器状态_上位机[5].NO[1]`
- S07 固体加样：`rotate_powder_cartridge_to_feed(position)` 使用 `S07上下料位置`，范围 1-10；`dose_powder(coarse_position, fine_position)` 使用 `S07粗注粉位置号`、`S07精注粉位置号`，范围 0-10，其中 0 表示跳过对应的粗注粉或精注粉阶段
- S07 粉桶暂存：机械臂 S071 使用 `S071取放料编号`；粉桶仓位为 `1-1` 到 `2-3`，对应 `传感器状态_上位机[3].NO[8]` 到 `传感器状态_上位机[3].NO[13]`
- S07 成品位：机械臂 S072 使用 `S072取放料产品`；位置 1/2 的传感器为 `传感器状态_上位机[3].NO[14]`、`传感器状态_上位机[3].NO[15]`
- S08 开关盖：`process_cap(工艺选择, 样品ID)` 中 `工艺选择` 为 1-6；瓶盖暂存写入 `S082瓶盖暂存位`，范围 1-5
- S08 取瓶位：机械臂使用 `S08取放料产品`、`S08取放料编号`；取瓶位置 1/2 对应 `传感器状态_上位机[3].NO[14]`、`传感器状态_上位机[3].NO[15]`
- S08 放瓶/瓶盖暂存位：机械臂放瓶位置 1-5 对应 `传感器状态_上位机[4].NO[0]` 到 `传感器状态_上位机[4].NO[4]`
- S08 倒料：机械臂使用 `S08倒料产品选择`，1=样品瓶 250ml，2=样品瓶 500ml
- S09 安全位：`home_position` 范围 1-4，对应 `S09原点信号_1` 到 `S09原点信号_4`
- S09 移液工艺位：`run_process` 写入 `S09TIP盒工位编号`、`S09TIP编号`、`S09液体瓶编号`；范围分别为 TIP 盒 1-2、TIP 1-96、液体瓶 1-5
- S09 加液/烧杯位：`station` 范围 1-5；抽液/放液写入 `S09抽液量`、`S09放液量`
- S09 机器人取放：机械臂使用 `S09取放料产品`、`S09取放料编号`；产品 1=TIP盒、2=液体试剂瓶、3=烧杯、4=测密度烧杯；TIP 位置 1/2 对应 `传感器状态_上位机[4].NO[5]`、`传感器状态_上位机[4].NO[6]`，烧杯位对应 `传感器状态_上位机[4].NO[7]`
