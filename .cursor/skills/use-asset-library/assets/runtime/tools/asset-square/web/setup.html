首次使用与 OSS 权限

技能安装成功不代表已获得资产库读取权限。网页浏览使用本地目录，模型可按需从 OSS 下载。

还没有权限？

请按 use-asset-library 技能中的 OSS 初始化指引取得只读权限和连接配置（endpoint、region、bucket、prefix）。权限范围应包含发布目录及所需模型对象的 GET 读取权限。

凭据只在本机安全配置。不要把密钥粘贴到聊天、此网页或技能包中；配置凭据后重启桥接服务。

在已安装的技能目录运行

python scripts/manage.py doctor
python scripts/manage.py doctor --config-dir <配置目录> --check-oss

第二条命令实际读取两个目录入口以检查权限，不下载模型或修改云端。具体配置、bootstrap、启动与 Blender 插件步骤见技能 references/oss.md 和 references/blender.md。

诊断结果

  • 未配置 OSS 地址：先取得非密钥连接配置。
  • 缺少凭据：在本机配置环境变量，或使用当前用户的凭据存储。
  • 401 / 403：凭据可能无效、过期或缺少读取权限，请按技能中的权限指引处理。
  • 404：检查存储路径和发布快照，不直接认定为无权限。
  • 连接失败：检查网络和 endpoint，恢复后重试。

已有完整本地镜像可离线使用；没有权限时保留本地资产与配置，不需要删除重装。
