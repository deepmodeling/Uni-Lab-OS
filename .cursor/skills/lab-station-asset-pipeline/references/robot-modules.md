# 机器人资产与品牌模块

机械臂和末端工具的代码/运动模型由 `unilab_robot_template` 品牌 distribution 维护；标准资产库持有 CAD/USD、来源、材质/物性和接口。导轨及工站的安装、工具、标定与工艺属于领域组合。与原生资产绑定的行为材料保留其来源，但不复制品牌驱动实现到资产包。

- 新增/补齐型号、驱动或运动模型，读 [维护品牌模块](../../maintain-robot-brand/SKILL.md)。
- 在领域项目使用、规划或验收移动后的资产，读 [OS 项目使用机器人](../../use-robot-in-os/SKILL.md)。
- 两个技能及其文档由机械臂仓的 `scripts/sync_robot_skills.py` 分发；更新规则回到真源，避免复制另一套 API 说明。

## 入库关联

仍使用 13 个公共字段。OS 设备模板 module 指向实际设备实现类；纯工程资产条目为 null。型号选择通过普通设备 config，品牌 asset 与目录 model.targets 保留固定 pin，反向索引按需生成并允许多个消费方。发行依赖由项目管理，不写入资产的型号选择器；品牌也不保存强制业务 UUID 回链。

目录条目 UUID、OS 模板 UUID 与工程 asset_id 分别校验，不建立一对一所有权。设备创建从原生注册模板的 module、构造参数 schema 和动作映射开始，存在定义或模型不授予 SDK/真机资格。多消费方必须显式选择品牌与型号。

补几何/物性或改变内容时按已授权修订流程处理；只做分类调整不搬动已发布包。公共关联、工程包摘要、品牌安装态和旧项目锁分别核对；资产移动后在新根解析、禁止旧根读取并复跑代表规划/OS 动作。下载工程包不自动同步公共目录，修改本地条目不等于 OSS 发布。
